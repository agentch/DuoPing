# 故障排查

- **登录已失效**：从已登录的 Duolingo 浏览器会话重新复制 `jwt_token` 并导入。
- **无法连接 Duolingo**：检查网络、代理或防火墙；应用会有限重试。
- **请求过于频繁**：等待一段时间后手动检查，不要连续刷新。
- **接口可能已变化**：更新 DuoPing；维护者应核对 `xp_summaries` 响应并更新脱敏契约样本。
- **没有 Windows 通知**：必须先安装应用；使用“测试通知”授予权限，并检查 Windows“设置 → 系统 → 通知”和通知中心。开发模式通知名称和图标可能不同。
- **开机后未运行**：关闭再开启“开机时自动启动”，然后在 Windows 启动应用列表中确认 DuoPing。
